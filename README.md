# Лист и глина

Демонстрационный интернет-магазин чая и чайных принадлежностей.

## Локальный запуск

Требуется Node.js 24. Из корня репозитория выполните:

```sh
node preview.mjs
```

Откройте http://127.0.0.1:5186/. Сервер создаёт локальную базу заказов SQLite и собирает витрину при запуске. После изменения исходников перезапустите сервер.

## Работа с проектом

- `catalog.mjs` формирует товары, цены и варианты фасовки. Артикулы зависят от порядка генерации. При расширении сохраняйте идентификаторы существующих товаров.
- `client.js` управляет фильтрами, корзиной и оформлением заказа.
- `server.mjs` формирует HTML и обрабатывает заказы, бонусы и запросы к СДЭК.
- `style.css` задаёт оформление витрины.
- `node build.mjs` собирает Worker в `dist/server/index.js`.

## Настройка магазина

Передайте настройки через переменные окружения процесса. Для локального файла настроек используйте `node --env-file=.env preview.mjs`.

| Переменная | Назначение |
| --- | --- |
| PORT | Локальный порт, по умолчанию 5186 |
| PICKUP_ADDRESS | Адрес самовывоза |
| CDEK_ID, CDEK_SECRET | Учётные данные API СДЭК |
| CDEK_FROM_POSTAL, CDEK_TARIFF | Индекс отправителя и код тарифа |
| METRIKA_ID | Номер счётчика Яндекс Метрики |

Для размещения Worker нужна база D1 с привязкой `DB` и схемой заказов из `schema.sql`. Обмен с Битриксом предстоит реализовать.
